How to set up Advanced RPC
  1. Inside CrossOver, install Funbit's ETS2 telemetry-server in the same bottle as ETS2.
  2. Run Ets2Telemetry.exe — it starts a local HTTP server on port 25555.
  3. Tick Show truck + city/cargo below.
  4. Paste http://localhost:25555/api/ets2/telemetry in the box (or point at a JSON file).
  5. Launch the game — Discord will show your truck, route & cargo.
Polled every 10 s. The launcher only reads truck.make/model and job.sourceCity/destinationCity/cargo — nothing else.

Step 2 — Create Bottle & Install Steam
Choose where to create your Wine bottle, then the app will initialise it and download SteamSetup.exe and run it inside the bottle.
If no bottle location is given, the bottle will be created at ~/Library/Application Support/TruckersMP-Launcher/TruckersmpBottle
⏳ Please wait for Steam setup to fully finish before proceeding to the next step.

Step 3 — Install DXMT
